# Workspace Customization Rules

MANDATORY GUIDELINES:
- This project utilizes a custom "SpecKit" architecture located in the `.specify` directory.
- **AT THE START OF EVERY TASK**, you MUST read `.specify/constitution.md` to understand the tech stack, coding style, state management rules, and project philosophy before making any modifications.
- Check the `.specify/workflows` directory for any specific workflow rules or templates when taking on complex feature development.
- You must strictly adhere to all rules defined in the SpecKit `.specify` folder when modifying code (e.g., keeping state centralized in `server.js`, using Vanilla JS + Tailwind in `index.html`, and ensuring strict anti-meta gaming masking).
